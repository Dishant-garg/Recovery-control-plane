Try to break it

The chain is not a claim about our discipline — it is recomputable. Change a single character in the file and re-run the check: 

sed -i '' '5s/"kind":"decision"/"kind":"tampered"/' {{ path }}
curl -s localhost:8000/api/verify?seed={{ seed }}&arm={{ arm }}

The same check runs offline as make verify-audit, which exits 1 on tamper — so it can gate a deployment rather than only inform a reviewer.
